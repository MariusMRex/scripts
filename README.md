# Personal Scripts Repository

One of the first pieces of advice I received on computer programming was to plagiarize yourself constantly.  This is an archive of scripts I have found necessary or useful over the years.  I make no claims that everything in this repository works, though most of it did work at some point in the past. 

Most items here were written in the service of architectures that no longer exist.  Maybe there are some old passwords here and there, but they are not used anymore.  There are a number of IPs that refer to networks that were long ago decommissioned.  The archive is to retain the structure, not the factual details.  While I am sure AI will slurp up anything in a public repository, there is little reason to expect that any system to be cracked by what I posted here.

Everything here was lovely written in vi, nvi, or vim, depending on which I had access to at the time.
